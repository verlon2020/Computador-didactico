# 🖥️ ¡Arma tu Computador! - Aplicación Didáctica para Niños

Una aplicación web educativa e interactiva diseñada para niños de 8 años,
donde aprenden las piezas del computador jugando a ensamblarlas.

## 🚀 Cómo ejecutar

1. Asegúrate de tener **Python 3** instalado
2. Abre una terminal en esta carpeta
3. Ejecuta el servidor:

```bash
python3 server.py
```

4. Se abrirá automáticamente tu navegador en `http://localhost:8080`

---

## 🎮 Características del juego

- **8 piezas para aprender**: Tarjeta madre, CPU, RAM, GPU, HDD, Fuente de poder, Cooler y Gabinete
- **Modelos 3D interactivos**: Cada pieza se puede ver en 3D y girar con el ratón
- **Sistema de puntos y niveles**: Desde Aprendiz hasta ¡Genio!
- **Datos curiosos**: Cada pieza tiene un dato divertido para recordar
- **Efectos de sonido y confetti**: ¡Celebra cada pieza instalada!
- **Gabinete visual**: Ve tu computador armándose pieza a pieza

## 🛠️ Tecnologías usadas

- **HTML5 + CSS3 + JavaScript** - Sin dependencias de framework
- **Three.js** - Modelos 3D interactivos (cargado desde CDN)
- **Web Audio API** - Sonidos de feedback
- **Python 3** - Servidor HTTP local
- **Google Fonts** (Fredoka One + Nunito) - Tipografía amigable para niños
